고소장·진정서 핵심 쟁점 분석기 (PWA 배포 패키지)

[포함 파일]
- index.html : 분석기 본문 웹 앱
- manifest.json : 앱 이름, 테마 색상, 홈 화면 아이콘 설정
- sw.js : 오프라인 실행 및 앱 설치를 위한 서비스 워커
- icon-192.png / icon-512.png : 앱 아이콘 이미지

[설치 및 공유 방법]
1. 이 폴더 전체를 Netlify Drop(app.netlify.com/drop), GitHub Pages, Vercel 등 정적 호스팅에 업로드합니다.
2. 생성된 HTTPS 주소를 팀원들에게 공유하거나 스마트폰/PC 브라우저로 엽니다.
3. 상단「앱 설치」버튼(또는 브라우저 메뉴 → 홈 화면에 추가 / 앱 설치)을 누르면 일반 앱처럼 설치됩니다.
